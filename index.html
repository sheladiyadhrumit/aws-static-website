What is CloudOps?

This is a real-world DevOps project demonstrating how modern software teams ship code to production. Every commit to the GitHub repository triggers an automated pipeline that builds, tests, and deploys the latest version to AWS EC2.

The site runs inside a Docker container managed by nginx, ensuring consistent behaviour from development laptop to cloud server.

How the Pipeline Works

01
📝
Code Push
Developer pushes code to the GitHub repository on the main branch.
02
🔔
Webhook Trigger
GitHub fires a webhook to Jenkins running on EC2, starting the pipeline.
03
🐳
Docker Build
Jenkins clones the repo and builds a fresh Docker image from the Dockerfile.
04
🔁
Container Swap
Old container is stopped and removed, new container is started on port 80.
05
✅
Live!
Updated website is live on the EC2 public IP. Total time: under 3 minutes.
